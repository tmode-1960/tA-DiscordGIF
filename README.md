# tA-DiscordGIF (v1.2)

Ein schlanker Windows-Desktop-Manager für animierte GIFs mit direkter Discord-Integration im bewährten **thomo.ART** Design.

## Features

- **Optisch an tA-MusicMaker angelehnt:** Elegantes Dark-Theme, aufgeräumte Sidebar, Kachel-Raster und flüssige Interaktionen.
- **Direktes Einfügen in Discord:**
  - Wähle ein GIF mit einem Klick aus.
  - Das Fenster fokussiert sofort Discord.
  - Das GIF wird per Zwischenablage eingefügt (`Strg + V`) und optional direkt mit `Enter` gesendet.
- **Globaler Hotkey (`Alt + G`):**
  - Drücke im Discord-Chat einfach `Alt + G`, um das Auswahlfenster aufzurufen.
- **Zwei Einfüge-Modi:**
  - **Datei-Upload:** Sendet das GIF als echte Bilddatei (perfekt für eigene Sammlungen).
  - **Link / URL:** Sendet die direkte Web-URL (z. B. Tenor/Giphy), ideal um Discord-Upload-Limits zu umgehen.
- **Kategorien & Tags:** Schnelle Live-Suche nach Tags, Titeln und Favoriten.
- **Drag & Drop Import:** Ziehe GIFs einfach per Drag & Drop in das Fenster oder gib eine URL ein.

## Starten

Einfach `start.bat` doppelklicken oder im Terminal ausführen:

```cmd
python server.py
```
